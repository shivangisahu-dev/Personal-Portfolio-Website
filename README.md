## 📌 About the Project

**Personal Portfolio Website** is a single-page website built using **HTML5 and CSS3** to present my technical skills, education, and projects in one place.

The layout uses **CSS Grid** for a two-column structure — a sticky sidebar with profile and contact details, and a scrollable main section with About, Skills, Education, and Projects.

---

## ✨ Features

* 🧭 **Section Navigation** — quick links to About, Education, Skills, and Projects
* 📱 **Fully Responsive** — adapts to tablet and mobile screens via media queries
* 🎨 **Custom Dark Theme** — consistent color palette across the site
* 🖱️ **Hover Interactions** — animated hover effects on skill cards, project cards, and nav links
* 🗂️ **Project Cards** — showcases projects with tech-stack tags

---

## 🛠️ Technologies Used

### 🌐 HTML5
Used for semantic page structure — sidebar, navigation, and content sections.

### 🎨 CSS3
Used for layout (Grid), responsive design (media queries), transitions, and the overall visual theme.

